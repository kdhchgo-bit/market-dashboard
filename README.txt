시장 관측실 · 수집기 통합 패키지

실행: MarketDashboard.exe
이 폴더를 통째로 보관하고 MarketDashboard.exe를 더블클릭합니다.
내장 Python으로 102개 수집기를 자동 실행하고(최대 4개 동시), collectors\data의 JSONL을 화면에 자동 반영합니다.
Python 설치와 데이터 폴더 선택은 필요하지 않습니다. GUI를 닫으면 이 프로그램이 시작한 수집기도 함께 종료합니다.
Windows .NET Framework 4.8을 사용합니다. 화면은 흰 배경이며 Pretendard를 폴더에 포함하여 글꼴 설치가 필요 없습니다.

조작
수집 중지 / 수집 시작: 자동 수집 중지 또는 재개
지금 수집 · F5: 예정된 수집을 지금 요청
저장 폴더 · Ctrl+O: collectors\data 폴더를 탐색기로 열기
F11: 전체화면 / 창 모드
Esc: 전체 상세창 → 종목·그룹 선택 → 전체화면 순서로 닫기
상단 닫기: GUI와 자식 수집기 종료

수집기 상태와 수신 상태
수집기 상태: 102개 프로그램의 실행·대기·완료·실패 및 실패 사유
수신 상태: 실제 저장 자료의 기본 70개 / 옵션 32개 수신·유효성·원본 시각·제외 사유
프로그램 실행 완료와 유효한 데이터 수신은 별개입니다. 0개 표시에는 미수신·지연·이력 부족 등 사유를 확인합니다.
키가 필요한 API는 기존 환경변수를 사용합니다. API 키를 패키지에 포함하지 않으며, 키 누락 등 실패 사유는 수집기 상태에 표시합니다.
기본 반복 주기: 가격봉·뉴스 5분, 옵션 15분, 일간 자료 1시간, 일정 6시간. 수집 호스트에서 원천별 예외를 조정할 수 있습니다.

화면 탐색
셋업 차트의 진입·TP·SL 선 또는 가격 박스를 마우스로 위아래로 끌면 가격·계획 평단·위험폭·손익비가 즉시 다시 계산됩니다. 진입은 구간 폭을 유지하여 함께 이동합니다. 가격 순서가 맞지 않는 이동은 화면에 이유를 표시합니다.
수동 조정값은 종목·롱/숏·시간봉별로 셋업 창이 열린 동안 유지하며, 5분 자료 갱신에도 적용합니다. ‘자동값 복원’으로 현재 셋업의 자동 계산값을 다시 불러옵니다.
가격·손익비 표시는 소수점 둘째 자리까지입니다. 손익비 계산에는 원본 가격 정밀도를 사용합니다.
하단 ‘롱·숏 셋업 · 통과 N’: 별도 셋업 화면을 엽니다. 왼쪽 20%에는 방향별 통과 종목을 순위대로, 오른쪽 80%에는 선택한 종목의 캔들·진입 구간·확인된 TP1~3·SL·손익비를 표시합니다.
셋업 화면에서 종목을 누르면 해당 롱 또는 숏의 계획이 열립니다. 5분·15분·60분봉을 선택할 수 있습니다.
진입·목표·손절은 최근 관측된 스윙 지지·저항과 OHLCV로 근사한 거래량 집중 가격대를 사용합니다. 손익비는 각 진입·TP·SL 가격에서 유동적으로 계산하며 수수료 반영 전 값입니다. 근거가 부족한 목표는 미확인으로 표시합니다.
셋업의 계산 근거와 파동 확인 상태를 함께 표시합니다. 파동 관찰의 범위는 현재 확보된 봉과 시간봉으로 표시합니다.
상단 매크로 클릭: 전체 원자재·달러·금리 자료
업종·테마·차트 선 클릭: 오른쪽 구성 종목과 통과·보류 근거, 종목 클릭: 해당 종목 상세
바닥 수신 상태 클릭: 102개 원천 검색
하단 일정·뉴스·옵션 위험 클릭: 전체 목록, 개별 뉴스 제목 클릭: 브라우저 원문
탐색 중에도 맨 위 판정은 유지됩니다. 계산은 완성 5분봉·상대강도·동시간대 거래대금 중앙값·옵션 호가 기준을 적용합니다.
거래대금은 과거 20일의 같은 시각을 비교합니다. 코인은 실행 첫 수집과 UTC 날짜 변경 후 첫 수집에서 부족한 과거 5분봉만 Binance 현물로 보충합니다. 보충분은 각 종목의 YYYY-MM-DD.history.jsonl에 저장하며 원래 수집 파일을 보존합니다. 미결제약정만 빠진 현물 봉도 가격과 거래대금에 사용합니다.
가격·레짐·거래대금·옵션을 모두 통과한 종목만 매수 후보로 표시합니다. 통과 종목이 없고 상대강도까지 통과한 종목이 자료 확인 또는 옵션 단계에 남으면 ‘관망 · 관찰 1순위’와 실제 보류 사유를 표시합니다.
미국 옵션 체인(77번 포함)에 원본 스냅샷 시각 없이 수신 시각만 있으면 확인 대기로 처리합니다.

폴더 구성·이동
MarketDashboard.exe와 .exe.config, runtime\, collectors\, fonts\를 함께 유지합니다. EXE만 빼서 실행하지 않습니다.
폴더 전체를 복사하여 다른 위치로 이동할 수 있습니다. 데이터 저장 위치는 패키지 내부 collectors\data입니다.
원본 102개 Python 수집기는 보존 복사했습니다. 기존 39개 대상 누적 JSONL도 초기 이력으로 포함했습니다.
자료의 최신 여부는 원본 시각으로 표시하며, 과거 이력 포함 자체가 현재 수신을 뜻하지 않습니다.
src\: C#·XAML 소스, build.ps1: Release 빌드, app.manifest·app.ico: 실행 설정·아이콘
fonts\: Pretendard 정적 글꼴, fonts\OFL.txt: SIL Open Font License

계산 설정·재빌드
MarketDashboard.exe.config의 appSettings 11개 임계값은 변경 후 프로그램을 다시 실행하여 적용합니다.
SpreadMax=0.15, BarStaleMin=10, UsChainMaxAgeMin=35, CoinChainMaxAgeMin=25
VolLookback=20, VolMinSamples=20, VolMultMin=1
EventBeforeMin=30, EventAfterMin=15, NewsWindowMin=60, UsoPct=0.95
프로젝트 폴더 PowerShell: powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
같은 폴더의 EXE가 재생성됩니다. runtime\·collectors\·fonts\는 함께 유지합니다. 중간 파일과 오류 기록은 work\삭제 아래에 둡니다.
